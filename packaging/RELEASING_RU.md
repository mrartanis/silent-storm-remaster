# Релизы движка

[English](RELEASING.md)

Поставьте на подготовленный коммит тег, начинающийся с `v`, и отправьте его в GitHub. Для предварительного релиза используйте тег с дефисом, например `v0.1.0-rc1`. Для каждой публикации нужен новый тег.

```sh
git tag -a v0.1.0 -m 'Engine v0.1.0'
git push origin v0.1.0
```

Workflow **Engine CI and release** собирает и проверяет Windows x64, Linux x64, macOS ARM64 и Android ARM64. После успешных проверок он публикует три настольных архива, `silent-storm-engine-<тег>-android-arm64.apk` и `SHA256SUMS`. Сбой загрузки оставляет черновик, который можно завершить повторным запуском.

Для проверки без публикации откройте **Actions → Engine CI and release → Run workflow** и выберите платформу. Артефакты хранятся семь дней. Pull request в `develop` и push в `develop` запускают полную проверку, push в `android` запускает только Android. В эмуляторе проверяются Vulkan, касания и возврат приложения после Home. Для тестов кампании нужны оригинальные игровые данные.

Релизный APK подписывается ключом из секрета `ANDROID_RELEASE_KEYSTORE` (PKCS#12 в base64) с паролем из `ANDROID_RELEASE_KEYSTORE_PASSWORD`. Сохраняйте этот ключ для последующих обновлений. В проверочных сборках используется временный ключ.

Инструкции для игроков доступны [на русском](../INSTALLATION_RU.md) и [на английском](../INSTALLATION_EN.md), включая отдельные инструкции для Android [на русском](../android/README.md) и [на английском](../android/README.en.md).

## Сетевая совместимость

`network-version.txt` содержит маркер формата, версию сетевой совместимости и семейство данных. Увеличьте вторую строку при несовместимом изменении сетевого формата. Третью меняйте только при намеренной смене семейства данных. Настольные архивы содержат этот файл. На Android его копируют из тега своего релиза рядом с `game.db` для сетевой игры.

## HD-пак

HD-пак выпускается отдельно с тегом `hd-*`. Для него используются замороженные PNG из [архива исходников](../data/README.md). Подробные команды подготовки, проверки и упаковки приведены в [английской версии инструкции](RELEASING.md#separate-hd-release).
