# v0.4

## Что изменилось

- **Сравнение оружия в инвентаре.** Подберите оружие в рюкзак и наведите на него указатель, чтобы сравнить с активным оружием. Shift раскрывает дополнительные характеристики; на Android они показаны сразу при удержании пальца. Сравнение до подбора с земли пока недоступно.
- **Настройки → Игра → Удобства.** Сравнение оружия и справка по клавишам включены по умолчанию; каждую опцию можно отключить.
- **Настраиваемая скорость чужих ходов.** По умолчанию ускорения нет. Можно выбрать ×2, ×3 или ×4 для одиночной пошаговой игры. Свой ход, реальное время, сценарные сцены и сетевые матчи сохраняют обычную скорость.
- **Справка по текущим клавишам.** Открывается через F1 или меню удобств. Уже назначенная другому действию F1 сохраняет своё назначение.
- **Mac: заменитель numpad.** Command + 0–9, `=`, `-` и `.` работают как клавиши цифрового блока. Опция отключается в настройках.
- Исправлены время жизни стандартного рукопашного оружия, сохранение списка целей и загрузка старых сохранений с неполными данными освещения.
- На Android исправлено отображение математических знаков в интерфейсе. Подсказки оружия из старых сохранений получают новый блок сравнения.

## What's changed

- **Inventory weapon comparisons.** Pick up a weapon into the backpack and hover over it to compare it with the active weapon. Shift reveals extra stats; Android shows them directly on touch hold. Comparison before picking up a weapon from the ground is not available yet.
- **Settings → Gameplay → Convenience.** Weapon comparisons and the keyboard reference are enabled by default; each can be disabled.
- **Configurable other-turn speed.** Acceleration is off by default. Choose ×2, ×3 or ×4 for single-player turn-based play. Your turns, real time, scripted sequences and network matches retain normal speed.
- **Current keyboard reference.** Open it with F1 or through Convenience settings. Existing F1 assignments keep their original behavior.
- **Mac numpad aliases.** Command + 0–9, `=`, `-` and `.` act as numpad keys. Disable them in settings if needed.
- Fixed default melee weapon lifetime, objectives-list saving and loading older saves with incomplete lighting data.
- Fixed mathematical symbols in the Android UI. Weapon tooltips restored from older saves receive the new comparison block.
