# v0.3

## Что изменилось

- **Android: пропуск роликов, катсцен и диалогов.** Удерживайте палец на экране две секунды. Кольцо под пальцем показывает время до пропуска.
- **ПК: исправлен кадр катсцен.** Область игрового изображения правильно совмещается с чёрными полосами сверху и снизу.
- **Лаунчер: импорт игровых данных из GOG.** Нажмите **Импорт из GOG…** и выберите полный офлайн-установщик `setup_….exe`, оставив все его `.bin` рядом. Поддерживаются оригинальная игра и Gold; одни только Sentinels не подходят.
- Инструменты игры с агентом поддерживают фазу подготовки сетевого матча.

**Лаунчер обновлён 7 ноября 2026.** Если вы уже скачивали его из этого релиза,
скачайте архив заново и распакуйте целиком, сохранив вложенные папки.
Для установки HD-пака по-прежнему нужен 7-Zip.

## What's changed

- **Android: skip videos, cutscenes, and dialogue.** Hold a finger on the screen for two seconds. A ring shows progress towards skipping.
- **Desktop: corrected cutscene framing.** The game view now stays aligned with the top and bottom letterbox bars.
- **Launcher: import GOG game data.** Click **Import GOG installer…** and select the full offline `setup_….exe`, keeping all accompanying `.bin` files beside it. Both the original game and Gold are supported; Sentinels alone is not supported.
- Agent play tools support the preparation phase of a network match.

**Launcher updated on November 7, 2026.** If you already downloaded it from this
release, download the archive again and extract it completely, keeping its
subdirectories. The HD pack still requires 7-Zip.
