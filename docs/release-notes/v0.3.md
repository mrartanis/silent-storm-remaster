# v0.3

## Что изменилось

- **Android: пропуск роликов, катсцен и диалогов.** Удерживайте палец на экране две секунды. Кольцо под пальцем показывает время до пропуска.
- **ПК: исправлен кадр катсцен.** Область игрового изображения правильно совмещается с чёрными полосами сверху и снизу.
- **Свежий настольный лаунчер включён в релиз.** Можно импортировать данные Silent Storm из офлайн-установщика GOG: выберите `setup.exe`, оставив все его `.bin` рядом. Для распаковки нужен установленный `innoextract`; сам установщик запускать не требуется. Поддерживаются оригинальная игра и Gold; одни только Sentinels не подходят.
- Инструменты игры с агентом поддерживают фазу подготовки сетевого матча.

## What's changed

- **Android: skip videos, cutscenes, and dialogue.** Hold a finger on the screen for two seconds. A ring shows progress towards skipping.
- **Desktop: corrected cutscene framing.** The game view now stays aligned with the top and bottom letterbox bars.
- **The updated desktop launcher is included.** Import Silent Storm data from an offline GOG installer by selecting `setup.exe` with all accompanying `.bin` files beside it. Install `innoextract` first; the installer itself does not need to run. Both the original game and Gold are supported; Sentinels alone is not supported.
- Agent play tools support the preparation phase of a network match.
