# v0.3

Архивы лаунчера обновлены 7 ноября 2026: распаковщик GOG и его библиотеки теперь
включены. Проверена реальная распаковка установщика с двумя `.bin` без системных
утилит на всех трёх платформах.
[Исходники обновлённого лаунчера](https://github.com/mrartanis/silent-storm-remaster/commit/02ce4e0a32de9b73ef730ea48ec27d2c4c73aab3).

Desktop launcher archives updated on November 7, 2026: the GOG extractor and its
libraries are now included. Real extraction with two `.bin` slices and no system
tools was verified on all three platforms.
[Updated launcher source](https://github.com/mrartanis/silent-storm-remaster/commit/02ce4e0a32de9b73ef730ea48ec27d2c4c73aab3).

## Что изменилось

- **Android: пропуск роликов, катсцен и диалогов.** Удерживайте палец на экране две секунды. Кольцо под пальцем показывает время до пропуска.
- **ПК: исправлен кадр катсцен.** Область игрового изображения правильно совмещается с чёрными полосами сверху и снизу.
- **Свежий настольный лаунчер включён в релиз.** Можно импортировать данные Silent Storm из офлайн-установщика GOG: выберите `setup.exe`, оставив все его `.bin` рядом. Распаковщик `innoextract` включён в архив лаунчера; отдельно устанавливать его или запускать установщик не требуется. Поддерживаются оригинальная игра и Gold; одни только Sentinels не подходят.
- Инструменты игры с агентом поддерживают фазу подготовки сетевого матча.

## What's changed

- **Android: skip videos, cutscenes, and dialogue.** Hold a finger on the screen for two seconds. A ring shows progress towards skipping.
- **Desktop: corrected cutscene framing.** The game view now stays aligned with the top and bottom letterbox bars.
- **The updated desktop launcher is included.** Import Silent Storm data from an offline GOG installer by selecting `setup.exe` with all accompanying `.bin` files beside it. The launcher archive includes `innoextract`; no separate installation or execution of the installer is needed. Both the original game and Gold are supported; Sentinels alone is not supported.
- Agent play tools support the preparation phase of a network match.
