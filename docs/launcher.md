# Настольный лаунчер Silent Storm Remaster

[English](launcher.en.md) · [Установка вручную](install.md)

Лаунчер загружает движок из стабильных релизов GitHub для Windows 10/11 x64,
Linux x64 (Ubuntu 24.04 или совместимая система) и macOS 15+ на Apple silicon.
На Linux интерфейс работает в нативном Wayland и в X11.
В разделе **Игровые данные** выберите папку вашей Silent Storm 1.2 из Steam или
GOG. В ней должны лежать `game.db`, `start.cfg`, `tree.mma`, `cfg`, `res`
и `scripts`. Для Gold Edition укажите папку основной Silent Storm.
В Windows кнопка **Найти игру** ищет установки Steam и GOG, пока папка
игры ещё не выбрана.

### Импорт установщика GOG

Если игра ещё не установлена, нажмите **Импорт из GOG…** и выберите свой
полный офлайн-установщик `setup_….exe`. Нужен отдельный
[innoextract](https://constexpr.org/innoextract/):

- macOS: `brew install innoextract`. Лаунчер находит Homebrew и при запуске из Finder.
- Ubuntu/Debian: `sudo apt install innoextract`.
- Windows: распакуйте innoextract и добавьте его каталог в `PATH`.

EXE не запускается; Wine и GOG Galaxy не нужны. Для составного установщика
оставьте все сопутствующие `.bin` рядом с `.exe`. Веб-загрузчик GOG Galaxy,
неподдерживаемые форматы установщиков и отдельная Sentinels не подходят.

Лаунчер извлекает только игровые данные Silent Storm 1.2; в Gold Edition
выбирается основная игра, без Sentinels и Windows EXE/DLL. После проверки
данные появляются в `game-data` внутри каталога данных лаунчера и выбираются
автоматически. Нужно не менее 4 ГиБ свободного места. Импорт можно отменить;
при ошибке или отмене прежние данные и выбранная папка сохраняются.
Повторный импорт требует подтверждения замены, включая локальные модификации
в `game-data`. Исходный установщик и сохранения игры не меняются.

### Движок и HD

1. Нажмите **Скачать** рядом с движком, затем **Играть**.
2. Для HD-текстур установите [7-Zip](https://www.7-zip.org/) и нажмите **Скачать**
   рядом с HD. Лаунчер принимает `7zz`, `7z` или `7za` из `PATH` и находит
   обычную установку 7-Zip в Windows и `brew install sevenzip` на macOS.
   Для текущего пака требуется около 12 ГБ
   свободного места. Переключатель HD находится в настройках графики игры.
3. При выходе новой версии нажмите **Обновить**. Кнопка **Восстановить**
   переустанавливает текущий движок, сохраняя HD-пак. Кнопка **Проверить** рядом с
   HD сверяет файлы и восстанавливает пак при повреждении. Играть можно без сети.

**Сохранения** открывают обычную папку сохранений игры. **Журнал** открывает
вывод последнего запуска. **Папка установки** открывает каталог движка, где
установленный HD-пак находится в подпапке `res-hd`. До установки движка
кнопка открывает каталог данных лаунчера. По умолчанию лаунчер проверяет
обновления при старте, а игра открывается на весь экран в окне без рамки.
На Linux установите системные библиотеки и Vulkan
по [инструкции для движка](install.md#установите-движок). Для окна лаунчера
в Ubuntu 24.04 используйте библиотеки вашей графической сессии.

```sh
# Wayland
sudo apt install libegl1 libwayland-client0 libwayland-cursor0 libwayland-egl1 libxkbcommon0
# X11
sudo apt install libegl1 libgl1 libxcb-cursor0 libxcb-icccm4 libxcb-keysyms1 \
  libxcb-shape0 libxcb-xinerama0 libxcb-xinput0 libxkbcommon-x11-0
```

## Запуск из репозитория

Нужен Python 3.11+ соответствующей архитектуры. Из корня репозитория выполните
следующие команды в виртуальном окружении.

```sh
python -m pip install -r launcher/requirements.txt
python launcher/launcher.py
```

Движок, HD и настройки лаунчера хранятся в каталоге данных приложения.
Чтобы выбрать другой диск, передайте `--storage "/путь/к/лаунчеру"`.
Язык берётся из системы и задаётся вручную через `--language ru` или
`--language en`.

## Сборка для распространения

На каждой целевой ОС из корня репозитория выполните следующие команды.

```sh
python -m pip install -r launcher/requirements-build.txt
python -m PyInstaller launcher/launcher.spec
```

Распространяйте каталог `dist/SilentStormLauncher` целиком. На macOS используйте
`dist/SilentStormLauncher.app`. Сохраняйте символические ссылки при упаковке
Linux и macOS.

## Проверка и публикация на GitHub

1. Запустите [Desktop launcher](../.github/workflows/launcher-release.yml) вручную
   для сборки проверочных архивов. Для проверки ветки до слияния
   используйте имя `launcher-check/…`. Workflow собирает архивы для всех трёх
   платформ, запускает лаунчер из распакованного архива, проверяет окно,
   читает список релизов и устанавливает крошечный локальный архив с проверкой
   SHA-256. Linux проверяется отдельно в X11 и в нативном Wayland.
2. Для выпуска используйте обычный тег движка `v*`. В [релиз движка](releasing.md)
   попадут три проверенных архива `silent-storm-launcher-*`, их хеши будут в
   `SHA256SUMS`. Имена архивов сохраняются между релизами для прямых ссылок
   из README.

Сборка macOS в CI использует локальную подпись. Для прохождения Gatekeeper
при обычном скачивании нужны подпись Developer ID и нотарификация Apple.
