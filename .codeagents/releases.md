# Сборка, CI и релизы

[English](releases.en.md) · [К списку задач](README.md)

- Команды и закреплённые версии зависимостей сверяйте с [инструкцией по сборке](../docs/build.md) и [релизным workflow](../.github/workflows/engine-release.yml). Тег движка собирает оптимизированные Windows x64, Linux x64, macOS ARM64 и Android ARM64. Для проверки без публикации используйте ручной запуск workflow.
- Запускайте тесты на тех платформах, которые затрагивает изменение. Linux CI использует программный Vulkan. macOS-тесты окна выполняются последовательно. Для Android проверяйте жесты, Vulkan и восстановление видимого кадра после сворачивания, а также содержимое подписанного APK. Сворачивание пишет отдельный автосейв, обычное возобновление сохраняет текущую сессию.
- Архивы движка содержат исполняемые файлы, зависимости, шрифты и инструкции. Оригинальные игровые данные, сохранения и HD идут отдельно от движка. Сетевую версию меняйте в [network-version.txt](../network-version.txt) только при изменении совместимости. Сверяйте состав архивов, контрольные суммы и итог CI перед объявлением релиза.
- Обычная сборка берёт готовый HD из локального кеша. Для сборки и CI без HD используйте `-DS2_BUILD_HD_TEXTURES=OFF`. Подготовку кеша, восстановление исходников и ручную пересборку выполняйте по [инструкции по HD](../docs/hd-authoring.md). При авторинге сохраняйте точные промпты, UV, альфу, материал и масштаб рисунка. Переиспользуйте принятые текстуры и обновляйте общие метаданные последовательно.
- HD публикуется отдельно от движка с `--latest=false`. [Установщик](../packaging/prepare_hd.py) выбирает последний стабильный релиз с тегом `hd-*` и проверяет тома и содержимое по индексу. Формат индекса и порядок публикации описаны в [инструкции по релизам](../docs/releasing.md).
