# Инструкции для агентов

[English](README.en.md) · [Основные правила](../AGENTS.md)

| Задача | Инструкция |
| --- | --- |
| Воспроизвести баг, проверить графику, сеть или FPS | [Игровые проверки](testing.md) |
| Разобрать и перенести изменения из upstream | [Перенос исправлений](upstream.md) |
| Проверить платформенную сборку, CI, релиз или HD-пак | [Сборка и релизы](releases.md) |
| Запустить матч с агентом или изменить его инструменты | [Игра с LLM](agent-play.md) |

Настройки своей машины можно сохранить в `.codeagents/local/`. Например, перечислите расположение копии игровых данных, каталога сборки и папки для результатов в `local/environment.md`. Пароли, ключи и токены храните в штатном хранилище учётных данных.
